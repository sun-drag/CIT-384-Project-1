Read a link before following it

The exact domain, source, and requested action matter more than a familiar-looking link. HTTPS encrypts a connection but does not prove a site is legitimate.

A link may appear in a class group chat, a search result, an email, or a document shared with you. Read the exact domain name before signing in or downloading anything. A familiar word somewhere in an address does not make it the real organization: campus.example.com and campus-example.com are different names. A padlock or HTTPS means the connection is encrypted; it does not prove the site owner is trustworthy. The image also reminds you to consider where the link came from and whether the site asks for a password, payment, or download you did not expect.

Preview a destination when possible and use the official site or app for sensitive accounts. Treat browser warnings as a reason to stop.

On a desktop, hover over a link to preview the destination, but remember that the displayed text and the actual destination can differ. For school, banking, or shopping accounts, open the official site or app yourself instead of trusting a message link. If a browser shows a security warning, treat it as a reason to stop and check. The FTC's phishing guide recommends contacting an organization through a phone number or website you already know is real.

What a malicious download might contain

Malware includes threats such as Trojans, worms, ransomware, spyware, and rootkits. Each can affect a device in a different way.

Malware is a broad term for harmful software. The image lists several forms. A Trojan pretends to be a useful file or program while carrying a harmful action. A virus attaches to other files and can spread when they run; a worm can spread across systems or networks. Ransomware may encrypt files and demand payment. Spyware quietly collects information, and a keylogger may record what you type. A rootkit tries to hide or maintain deep access. Some unwanted bundled software, often called bloatware, is annoying or resource-heavy without necessarily being malicious.

A single file can combine threats, such as a Trojan installing spyware. Unexpected installers, archives, and misleading extensions deserve extra caution.

These categories can overlap. A fake study tool might be a Trojan that installs spyware, while a malicious attachment might start a ransomware infection. Be especially careful with unexpected executable files, installers, compressed archives, browser extensions, and documents asking you to enable macros. A filename such as lecture-notes.pdf.exe is an executable program, not a PDF. The FTC's malware guide recommends using security software and avoiding unfamiliar download sites.

Make a safer decision before opening a file

Choose official sources and scan uncertain files before opening them. Confirm with a sender when an unexpected class file arrives.

Start with the source. For software, use the developer's official site or a trusted app store; for a file from a classmate, ask whether they meant to send it if the message is unexpected. Keep your browser, operating system, and security software updated. On Windows, you can right-click a downloaded file, choose Show more options if that menu appears, and select Scan with Microsoft Defender. Microsoft's file-scan instructions describe the process.

A clean scan does not guarantee safety. If the source or file type still seems wrong, leave it unopened and ask for help.

A scan is one piece of evidence, not a guarantee. A new threat may not yet be recognized, and a file that passes a scan can still be inappropriate to run. If the source, file type, or request still looks wrong, do not open it. Ask campus IT when the file relates to a school account or device.

How VirusTotal helps and what it cannot prove

VirusTotal checks public files and URLs using many scanners and can show existing reports. A zero-detection result is still not proof of safety.

The screenshot shows VirusTotal's File, URL, and Search choices. VirusTotal combines results from many antivirus engines and website scanners, so it can provide another clue about a public file or link. You can search an existing file report by its hash, or submit a nonsensitive file or public URL for analysis. Read the actual findings and comments rather than treating a single number as a final verdict. A result with no detections is not proof that a file or site is safe.

Keep private documents, account information, and token-bearing links out of public scanning services. Reaching the real service yourself is often safer.

Do not upload private coursework, personal documents, account data, or links containing private tokens. VirusTotal's search documentation explains that submissions and queries contribute to its dataset and warns against submitting sensitive information. If a link came in an unexpected message, the simplest safe choice is usually to ignore it and reach the service independently, even if a scanner does not flag it.

Check the source, file type, and request. Scan if needed, then stop if anything still feels inconsistent.

If you already opened the file

If a suspicious file was opened, stop sensitive sign-ins, update security software, and scan the device. Change exposed passwords from a trusted device.

Stop entering passwords on the affected device, update your security software, and run a full scan. If a scanner finds malware, follow its removal instructions. From a trusted device, change passwords for accounts you used after the suspicious download and enable MFA. Contact campus IT for help with a school computer or account.
